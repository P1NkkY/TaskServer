# Названия для SQL файлов миграции

Придерживайтесь этих правил:
- Добавляйте глагол действия: `create_`, `alter_`, `drop_`, `add_` и др.;
- Указывайте объект БД: `table_`, `index_`, `column_` и др.;
- Делайте имена читаемыми: `create_script_list_table.sql`;
- Используйте паттерн: `{год}_{месяц}_{день}_{порядковый номер}_{суть}.sql`.

*P.S. Порядковый номер используется только в том случае если в один день было добавлено более одного файла миграции.*
